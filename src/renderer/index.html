设置

下载目录
默认保存位置；同名冲突由核心自动编号，不覆盖已有文件。右键单文件也可随时选择「下载到指定位置…」。
下载保存方式
默认全部保存到上方同一目录；切换为「每次询问」后，每次点击下载都可单独指定目标目录。
同时上传的文件数
多文件上传时同时进行的任务数（不设硬上限，建议 1–6，默认 2）。
上传分片并发
单文件并发上传分片数（不设硬上限，建议 1–12，默认 3；设为 1 使用顺序上传）。
同时下载的文件数
多文件下载时同时进行的任务数（不设硬上限，建议 1–6，默认 2）。
下载策略
自动按文件大小分配连接；顺序下载使用单连接；并行下载按连接上限运行。
单文件下载连接上限
单文件并发分片连接数（不设硬上限，建议 1–32，默认 16；新任务及恢复任务生效）。
当前并行设置高于建议阈值，过高可能导致内存占用升高、界面卡顿或触发服务端限流，请按设备与网络情况酌情调整。
主题外观
深浅色主题持久化保存，启动即自动应用。
账号
查看当前登录状态。
AI 实验室 Beta 测试功能
默认关闭以保持极简网盘体验。手动开启后，侧栏将展示「对话 (Beta)」并展开下方「Agent / MCP 接入」配置；全部 AI 能力均运行在本地授权边界内且默认只读。

写入模式

删除权限

MCP 配置
复制到 MCP 客户端配置文件中即可连接本客户端；连接凭据由客户端自动读写，无需手工填写。
未读取
作者服务器连接（可选） 已关闭 · 零外传
默认关闭：未开启时本应用承诺绝不向作者服务器发送任何数据。开启后仅在端到端加密下接收最新更新日志/直链下载包、提交应用内反馈，并可能上传脱敏后的非敏感运行/性能/下载速度数据（绝不包含文件名、路径、Cookie、账号等隐私），帮助持续改进应用。
提示：服务器部署于海外节点（日本东京），国内直连可能出现连接失败或较慢，有代理/梯子开启后即可顺畅连接；没有也没关系，完全不影响网盘本地核心使用。
链路安全：HTTPS TLS 1.3 + X25519/AES-256-GCM 端到端加密 + Ed25519 更新清单签名校验
在线更新与公告
开启连接后，可获取作者发布的最新更新日志、公告通知，并直接从服务器高速直链下载经过 SHA-256 校验的新版安装包。
