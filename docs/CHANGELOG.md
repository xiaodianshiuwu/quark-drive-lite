# 版本变更记录

本文件记录面向用户的版本变更。发布包的详细验证范围见 [平台支持与构建](PLATFORM_SUPPORT.md)。

---

## 0.2.0-rc.1 — 2026-10-14（预发布）

首个公开发布的预发布版本，提供 Windows x64、Linux x64、macOS Apple Silicon 与 Intel 的预构建包。

### 新增

- **免系统密码的登录状态存储**：登录资料改用本机随机密钥与 AES-256-GCM 加密保存，日常启动不再要求输入系统密码或解锁钥匙串。
- **三平台预构建包**：Windows x64、Linux x64、macOS arm64 与 macOS x64，每个包附带 SHA-256 校验文件。
- **三平台原生 CI**：Windows、Ubuntu、macOS（Intel 与 Apple Silicon）四个作业分别执行检查、测试、构建与产物冒烟。
- **旧格式迁移**：提供显式迁移入口，可将早期使用系统加密保存的登录资料转换为新格式，并在迁移前保留原密文备份。

### 优化与修复

- 修复传输完成后的结果核对逻辑，同名等长文件不再被误判为上传成功。
- 修复下载断点恢复：续传前校验文件标识、总长度与 ETag，不匹配时安全地重新下载，避免产生损坏文件。
- 修复设置落盘失败后界面仍显示未保存新值的问题，失败时恢复为已保存的设置。
- 修复 Cookie 已全部过期时仍被判为已登录的问题。
- 修复 HTTP 请求 UA 中固定的 Chromium 版本与运行时不一致的问题。
- 修复主窗口导航与弹窗拦截安装过晚的问题，现在在窗口创建时立即生效。
- 修复 Windows 便携包二次重写应用归档可能影响构建完整性的问题。

### 说明

- macOS 使用 ad-hoc 签名，未做 Developer ID 公证；Windows 未做发行者签名。首次安装时会出现系统安全提示。
- 登录资料的密钥与密文存放在同一用户目录，备份或迁移时需同时保存 `session.bin` 与 `session.key`。
- 下载的临时文件与进度文件可跨进程复用；上传的分片进度只在当前进程内保留。

## 0.1.0 — 2026-10-13（未单独发布）

功能开发阶段，确立了文件管理、上传下载引擎、登录与会话存储、传输任务队列的完整实现，并完成一次全量代码审查与缺陷修复。

### 主要修复

- **上传分片签名**：实际 PUT 请求补齐签名中声明的参数，修复分片上传无法可靠工作的问题。
- **顺序写入适配**：实际存储端拒绝并发 PUT，改为分片预读并发、写入按编号顺序执行。
- **请求中止生命周期**：中止与超时现在覆盖整个响应体读取过程，下载可以及时停止。
- **任务并发竞态**：暂停后立即继续、重试运行中的任务、取消时先清理文件等情况不再产生多个执行器与文件竞态。
- **同名下载冲突**：并发下载同名文件不再共用临时文件，收尾时也不会覆盖已存在的文件。
- **分片失败处理**：分片失败后中止其余写入，并校验 `Content-Range`，必要时安全降级为单流下载。
- **加密失败处理**：正式模式下加密失败不再写入明文；命令行工具可正确读取应用加密的登录资料。
- **IPC 来源校验**：仅接受主窗口主框架的调用，其他来源一律拒绝。
- **请求重试策略**：非幂等的 POST 请求默认不自动重放；下载只重试瞬时错误，上传在分片级重试。
- **搜索结果修正**：搜索仅使用服务端实际生效的参数，不再使用会被静默忽略的参数名。
- **容量显示修正**：存储容量取自正确字段，不再把下载流量当作存储用量。
- **列表与选择行为**：修复旧目录请求覆盖新目录、多选切换不正确、目录选择器只能读取第一页等问题。
- **退出登录**：停止传输并清除登录凭证，同时保留用户设置。

### 说明

- 该版本未单独发布安装包，其成果包含在 `0.2.0-rc.1` 中。
