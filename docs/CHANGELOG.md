# 版本变更记录

本文件记录面向用户的版本变更。发布包的详细验证范围见 [平台支持与构建](PLATFORM_SUPPORT.md)。

## 0.3.0-beta.1 — 2026-11-22（Tauri 2 + Rust 正式主线替换）

将 Tauri 2 + Rust 原生运行时全量合入 `main` 主分支，彻底取代旧版 Electron 运行时；修复目录无法返回上一级（Issues #3 / #4），重构前端 UI/UX 与动效，升级文件管理与传输工作台，并新增默认关闭的 AI 实验室（Beta 测试功能）。

### 架构与性能升级

- **Tauri 2 + Rust 全量主线替换与精简**：去除 Electron 运行时、历史遗留脚本及重装前备份模块（同时彻底移除 `rusqlite` / SQLite C 编译依赖），安装包体积与内存占用进一步下降，冷启动更快。
- **自研下载/上传引擎深度重构提速**：
  - 下载引擎改用单共享文件句柄无锁随机位置写入（Unix `write_all_at` / Windows `seek_write`）+ `256 KiB` 缓冲批写、自适应 `1–4 MiB` 分片粒度、单流下载边写边算哈希（免二次读盘），进度推送合并至 `256 KiB / 100 ms`，大幅降低锁竞争与系统调用开销。
  - 上传引擎将大文件检验与分片读取下沉至 `2 MiB` 缓冲同步块 I/O，分片检查点批量落盘，显著降低高并发内存与磁盘开销。
  - Rust 事件驱动调度器（`tokio::sync::Notify` 零轮询唤醒 + 150 ms 推送节流），HTTP 连接池提升至每主机 128 空闲长连接与 90 s 保活。
  - 放宽传输并发与连接数上限（不设硬上限，保留推荐阈值超限提醒），下载/上传并发信号量扩容至 1024 槽位 / 512 MiB 缓冲区。
- **前端虚拟滚动、目录缓存与智能自动刷新**：
  - SWR 目录 LRU 缓存 + 同步节点池虚拟滚动 + 骨架屏与暗色首帧防闪烁。
  - 新增文件列表与账号状态智能自动刷新：当前目录每 60 秒后台静默刷新；账号状态与剩余空间每 90 秒（1~2 分钟）自动同步一次（上传/删除完成后立即补刷）；下载/上传队列 `< 10` 个任务时每完成一项自动刷新，`≥ 10` 个任务时每 15 秒节流刷新并在批次完成后补一次收尾刷新。

### 关键修复（含 Issues #3 / #4）

- **彻底修复多级目录无法返回上一级与深层鼠标导航**：
  - 顶部常驻「后退 / 前进 / 上一级」导航按钮，支持鼠标侧键与 `Alt+↑` / `Backspace` / `Alt+←` / `Alt+→` 快捷键。
  - 深层目录（4 级及以上）常驻根目录「全部文件」，中间祖先自动折叠至「···」下拉菜单一键直达，同时支持鼠标滚轮横向滚动与 `<`/`>` 滚动箭头，彻底解决 Windows 与 Mac 鼠标用户深层路径难以回退的问题。
  - Rust `fs.crumbs` 在 `path_list` 返回空、仅根目录或仅当前节点时自动回退 `/1/clouddrive/file/info?_fetch_full_path=1` 重建父级链路；前端 `loadCrumbs` 与 `goUp` 内置多重兜底。
  - 升级移动/复制目录选择器：新增顶部「上一级」和弹窗内「新建文件夹」按钮与目标路径预览。
- **修复多选与交互细节**：复选框改为累加多选、整行单击选中、文件夹行隐藏无意义的下载按钮、危险删除弹窗取消回车误确认、支持列表空白处与多选右键菜单。

### 新增功能与 UI/UX 重构

- **全新定制应用图标与精致双色调图标体系**：替换全平台 `.icns` / `.ico` / PNG 应用图标（超椭圆圆角透明底），重绘应用内双色调云盘与文件类型 SVG 图标。
- **现代桌面 UI/UX 与实时状态展示**：
  - 文件子工具栏「压缩包」与「最新修改」中间空隙新增实时传输进度胶囊（活跃传输时实时显示方向、文件名、进度条与当前速度，点击直达传输中心）。
  - 灵活下载目录：支持默认同一目录或「每次询问目录」，右键菜单与文件详情侧栏新增单文件/批量「下载到指定位置…」。
  - 文件管理工作台增强：分类快筛标签、可点击列头与下拉排序、列表/网格双视图切换（持久化记忆）、右侧可收起「文件详情」面板、底部状态栏；760×520 最小窗口全视图零横向溢出。
- **可选的作者服务器连接（默认关闭 · 端到端加密）**：
  - 首次启动弹窗征询用户意愿：选择不开启则底层强制零外传；开启后支持接收更新日志与公告、直链高速下载经 Ed25519 验签 + SHA-256 校验的安装包、侧栏「反馈」页直发意见（可选附带并预览脱敏日志）以及上传严格脱敏的非敏感性能与错误摘要。
  - 明确提示海外节点（日本东京）连接特性，附带独立服务端与管理控制台（`server/qdl-hub/`）。
- **AI 实验室（Beta 测试功能 · 默认关闭）**：内置「对话（Beta）」与「Agent 接入 / MCP 网关（Beta）」，明确标注为 Beta 测试功能且默认完全关闭（不显示入口、不启动后台监听），需用户在 **设置 → AI 实验室** 手动开启后方可使用。

## 0.2.0-rc.1 — 2026-10-14（预发布）

首个公开发布的预发布版本，提供 Windows x64、Linux x64、macOS Apple Silicon 与 Intel 的预构建包。

### 新增

- **免系统密码的登录状态存储**：登录资料改用本机随机密钥与 AES-256-GCM 加密保存，日常启动不再要求输入系统密码或解锁钥匙串。
- **三平台预构建包**：Windows x64、Linux x64、macOS arm64 与 macOS x64，每个包附带 SHA-256 校验文件。
- **三平台原生 CI**：Windows、Ubuntu、macOS（Intel 与 Apple Silicon）四个作业分别执行检查、测试、构建与产物冒烟。
- **旧格式迁移**：提供显式迁移入口，可将早期使用系统加密保存的登录资料转换为新格式，并在迁移前保留原密文备份。

### 优化与修复

- 修复传输完成后的结果核对逻辑，同名等长文件不再被误判为上传成功。
- 修复下载断点恢复：续传前校验文件标识、总长度与 ETag，不匹配时安全地重新下载，避免产生损坏文件。
- 修复设置落盘失败后界面仍显示未保存新值的问题，失败时恢复为已保存的设置。
- 修复 Cookie 已全部过期时仍被判为已登录的问题。
- 修复 HTTP 请求 UA 中固定的 Chromium 版本与运行时不一致的问题。
- 修复主窗口导航与弹窗拦截安装过晚的问题，现在在窗口创建时立即生效。
- 修复 Windows 便携包二次重写应用归档可能影响构建完整性的问题。

### 说明

- macOS 使用 ad-hoc 签名，未做 Developer ID 公证；Windows 未做发行者签名。首次安装时会出现系统安全提示。
- 登录资料的密钥与密文存放在同一用户目录，备份或迁移时需同时保存 `session.bin` 与 `session.key`。
- 下载的临时文件与进度文件可跨进程复用；上传的分片进度只在当前进程内保留。

## 0.1.0 — 2026-10-13（未单独发布）

功能开发阶段，确立了文件管理、上传下载引擎、登录与会话存储、传输任务队列的完整实现，并完成一次全量代码审查与缺陷修复。

### 主要修复

- **上传分片签名**：实际 PUT 请求补齐签名中声明的参数，修复分片上传无法可靠工作的问题。
- **顺序写入适配**：实际存储端拒绝并发 PUT，改为分片预读并发、写入按编号顺序执行。
- **请求中止生命周期**：中止与超时现在覆盖整个响应体读取过程，下载可以及时停止。
- **任务并发竞态**：暂停后立即继续、重试运行中的任务、取消时先清理文件等情况不再产生多个执行器与文件竞态。
- **同名下载冲突**：并发下载同名文件不再共用临时文件，收尾时也不会覆盖已存在的文件。
- **分片失败处理**：分片失败后中止其余写入，并校验 `Content-Range`，必要时安全降级为单流下载。
- **加密失败处理**：正式模式下加密失败不再写入明文；命令行工具可正确读取应用加密的登录资料。
- **IPC 来源校验**：仅接受主窗口主框架的调用，其他来源一律拒绝。
- **请求重试策略**：非幂等的 POST 请求默认不自动重放；下载只重试瞬时错误，上传在分片级重试。
- **搜索结果修正**：搜索仅使用服务端实际生效的参数，不再使用会被静默忽略的参数名。
- **容量显示修正**：存储容量取自正确字段，不再把下载流量当作存储用量。
- **列表与选择行为**：修复旧目录请求覆盖新目录、多选切换不正确、目录选择器只能读取第一页等问题。
- **退出登录**：停止传输并清除登录凭证，同时保留用户设置。

### 说明

- 该版本未单独发布安装包，其成果包含在 `0.2.0-rc.1` 中。
