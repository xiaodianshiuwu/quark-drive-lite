# 当前产品定义（Tauri 开发版）

本文件描述当前有效产品范围。原始依据为用户的 `Quark_Agent_Execution_Prompt.md` 及 2026-10-19 独立审计任务；旧 Electron 文档与历史审查记录不能替代当前实现及验收证据。

## 用户目标

1. 在 Tauri 2 / Rust 中保留文件浏览、分页、搜索、新建、重命名、移动、复制、回收站删除、上传下载、传输控制、登录与设置。
2. 保留 20 个 Agent 工具、按目录授权的本机网关、计划绑定、脱敏操作记录及用户自配模型的内置对话。GUI 操作与 Agent 授权独立，Agent 默认只读。删除使用 dry-run 与逐项名称确认，不能绕过账号和范围检查。
3. 为 Windows 重装前备份提供原生本地目录选择、保留目录结构的增量发现、持久任务、受控上传、停止恢复及明确的核验报告。不能通过全盘预扫描、一次性 FileList 或一次性入队十万任务实现。
4. 独立审查与实测后直接修复确认缺陷，改进 UI/UX，按证据区分验收等级。

## 备份产品约束

- 一次一个会话。身份来自 Rust Core 的持久登录绑定，源路径规范化，目标 fid 参与身份。前端不能选择或伪造账号；重新登录有意隔离旧登录任务。
- 选择源和云端目标后可直接开始。可选预览最多 5000 项，明确总量未知，不阻塞首次上传。
- 默认发现批次 500，持久库待处理高/低水位 1000/500，上传并发 2。待处理量包括 discovered、pending、uploading、verifying。水位必须约束扫描，而非仅约束内存 channel。
- 后台扫描不排序或物化整个目录，最多 128 层目录迭代器；超限、链接、重解析点、无法读取、Windows 名称/长路径风险必须进入可导出的排除记录，不能悄悄漏掉。
- 任务清单分页，允许暂停、继续、重试失败、取消、导出。取消保留本地源和云端已上传成果；等待本会话扫描与 worker 退出后才允许重新开会话。
- 源变化、同名冲突、提交不确定必须显式报告，不能冒充成功。达到失败上限后暂停自动工作；用户可重试，或继续其他项并保留失败报告。
- 单个文件和分片并发、发现批次、队列水位与带宽是不同设置。带宽限制覆盖实际 PUT 流，允许约 64 KiB 的发送粒度；分片大小遵循服务端协议，不承诺客户端可任意修改。
- 所有扫描项无缺失并核验通过后才显示“备份核验通过”。任何未处理、失败、跳过、排除或抽样失败都不能被成功文件数量掩盖。
- 默认哈希核验为 1% 且 5–20 项；选择全量必须逐文件下载流式核对，不能仍截到 20 项。未经核验的 ETag 不当作内容哈希。空目录也应核对。
- 不执行重装、格式化或本地源删除，不将软件测试通过描述为用户私人备份已完成。

## 界面与交互

中文、统一深浅色设计变量、可见的错误与空态、键盘可操作的原有控件。保留全部既有页面；本轮重点重构风险较高的备份流程，而不无理由重写已稳定界面。最低桌面窗口按配置为 760×520；通知数量有界，长路径折行，任务分页显示。

## 支持与验收边界

macOS 为本次实际开发与运行平台。Windows 10/11 x64 是主要备份目标；Windows 管道、长路径、保留名、junction、大小写目录及安装产物须在 Windows 验收，不能由 macOS 测试替代。具体结果以独立审计报告为准。

## 非目标

自动双向同步、永久清空回收站、官方客户端会员/推广功能、自动重装。外部 MCP 客户端使用 Node.js 运行随应用内置的适配脚本，桌面应用本身不依赖 Node 运行时。
