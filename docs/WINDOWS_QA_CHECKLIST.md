## 1. 交付产物核对

在 Windows 实机核对 SHA256（PowerShell）：

```powershell
Get-FileHash .\QuarkDriveLite-0.3.0-beta.1-Windows-x64-setup.exe -Algorithm SHA256
Get-FileHash .\QuarkDriveLite-0.3.0-beta.1-Windows-x64-portable.zip -Algorithm SHA256
```

与 `SHA256SUMS.txt` 逐字节一致后继续。

## 3. 登录与会话持久化

- [ ] **扫码登录**：点击右上角登录 → 弹出原生独立登录窗口 → 夸克 App 扫码完成 → 主窗口自动刷新账号名、会员标签、网盘空间与根目录列表。

## 6. 上传、下载、灵活目录与并发上限

- [ ] **下载目录灵活选择**：默认保存到同一文件夹；在设置切换「每次询问目录」或右键点击「下载到指定位置…」可单文件指定独立目录且不覆盖默认目录。
- [ ] **宽松并发上限与阈值提示**：设置页可输入高于原限制的并发值（如单文件下载连接 `48`），保存生效并弹出温和的过载风险提示条，不设人为硬上限。

- [ ] **定位本地文件**：已完成的下载任务点击「打开所在文件夹」，正常唤起 `explorer.exe /select,"..."` 并高亮定位到含空格/逗号/中文的文件。
- [ ] **传输中心批量控制**：状态筛选标签、侧栏实时速率胶囊、「全部暂停 / 全部继续 / 重试失败 / 清除已结束记录」全部正常。

## 8. AI 实验室（Beta 测试功能 · 默认关闭）

- [ ] **首次启动默认关闭**：侧边栏**不显示**「对话」入口；设置页「Agent 接入」卡片**隐藏**；无后台命名管道监听。
- [ ] **手动开启 Beta**：进入 **设置 → AI 实验室（Beta 测试功能）** 点击「开启 Beta」→ 侧边栏出现带 `Beta` 标识的「对话」，下方展开「Agent 接入（Beta）」；重启客户端后保持开启。
- [ ] **内置对话（Beta）**：填写 OpenAI 兼容端点 + API Key + 模型名 → 测试连接成功 → 发送只读查询（如“列出根目录”）正常调用工具并返回结果。
- [ ] **Agent 网关（Windows Named Pipe）**：启用 Agent 接入后状态为绿色「运行中」，监听地址显示 `\\.\pipe\...`；执行 `node tools/agent-cli.js status` 可连通并返回状态。
- [ ] **随时关闭**：切换回「关闭」后立即隐藏入口并恢复极简模式；再次开启后已保存配置仍在。
