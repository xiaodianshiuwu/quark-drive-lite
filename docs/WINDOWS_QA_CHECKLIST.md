# Windows 10/11 x64 实机验收清单（v0.3.0-beta.1）

本文档用于在真实 Windows 10/11 x64 机器上对 **夸克网盘极简版 v0.3.0-beta.1（Tauri 2 + Rust）** 进行发布前实机验收。  
注：macOS 交叉编译阶段仅验证静态编译、PE/子系统、DLL 导入表、NSIS/ZIP 完整性与 SHA256，**不可替代 Windows 实机运行验收**。

## 1. 交付产物核对

在 Windows 实机核对 SHA256（PowerShell）：

```powershell
Get-FileHash .\QuarkDriveLite-0.3.0-beta.1-Windows-x64-setup.exe -Algorithm SHA256
Get-FileHash .\QuarkDriveLite-0.3.0-beta.1-Windows-x64-portable.zip -Algorithm SHA256
```

与 `SHA256SUMS.txt` 逐字节一致后继续。

## 2. 安装、启动与基础外观

- [ ] **NSIS 安装包（`setup.exe`）**：默认「仅当前用户」安装无需管理员权限；语言选择（简体中文 / English）正常；安装完成自动创建开始菜单/桌面快捷方式并成功启动。
- [ ] **免安装便携版（`portable.zip`）**：解压至含中文和空格的路径（如 `D:\测试 工具\夸克极简版`），双击 `QuarkDriveLite.exe` 正常启动，无报错弹窗。
- [ ] **WebView2**：正常渲染主窗口（默认 `1200×780`），缩放至 `760×520` 最小尺寸时所有视图无横向溢出；高分屏（125% / 150% / 200% DPI）字迹清晰不模糊。
- [ ] **快捷键提示自适应**：搜索框快捷键标签与底部状态栏显示 `Ctrl+F`（非 `⌘F`）。
- [ ] **深浅色主题切换**：设置页切换浅色/深色立即生效；重启客户端无首帧白屏闪烁。

## 3. 登录与会话持久化

- [ ] **扫码登录**：点击右上角登录 → 弹出原生独立登录窗口 → 夸克 App 扫码完成 → 主窗口自动刷新账号名、会员标签、网盘空间与根目录列表。
- [ ] **重启持久化**：关闭客户端再打开，保持已登录状态，无需重复扫码；资料保存在 `%APPDATA%\cn.quarkdrive.lite.tauri`（`session.bin` 为加密密文，不含明文 Cookie）。
- [ ] **安全退出**：点击退出登录后列表、选中态、空间信息立即清空，重启保持未登录。

## 4. 核心回归：多级目录导航（Issues #3 / #4）

- [ ] 进入 2~3 层嵌套子目录，点击顶部 **「↑ 上一级」** 按钮逐级稳定返回父目录。
- [ ] 点击多级面包屑任意祖先节点直达对应目录；当前目录项置灰不可重复点击。
- [ ] 点击顶部 **「← 后退 / → 前进」** 按钮、鼠标侧键、`Alt+↑`、`Backspace`、`Alt+←`、`Alt+→` 全部生效。
- [ ] 根目录内按 `Alt+↑` 或「上一级」按钮处于禁用态，无异常提示。
- [ ] 全盘搜索后点击「← 返回目录」准确回到搜索前目录；点击搜索结果中的子文件夹后点「上一级」准确返回该文件夹的真实父目录。
- [ ] 移动/复制弹窗内进入子目录，点击弹窗顶部 **「上一级」** 和 **「新建」** 按钮正常工作。

## 5. 文件管理与交互体验

- [ ] **分类快筛**：点击「全部 / 文件夹 / 图片 / 视频 / 文档 / 音频 / 压缩包」筛选准确，底部状态栏实时显示筛选计数。
- [ ] **排序与双视图**：列头排序与下拉排序切换正常；列表 / 网格视图切换流畅且重启后记忆。
- [ ] **右侧文件详情面板**：单选显示文件元信息与快捷操作；多选显示汇总计数、总大小与批量操作按钮。
- [ ] **多选与右键菜单**：复选框勾选为累加多选；Ctrl/Shift 多选正常；右键文件行与列表空白处分别弹出对应菜单。
- [ ] **真实写操作（仅在新建测试目录内操作）**：新建文件夹 → 重命名 → 移动 → 复制 → 删除（默认不误触回车确认删除），均无残留脏缓存。

## 6. 上传、下载与资源管理器集成

- [ ] **拖拽上传**：从 Windows 资源管理器拖拽单个/多个文件（含中文/空格文件名）到窗口，出现拖拽遮罩并顺利入队上传。
- [ ] **分片下载与断点续传**：下载大文件（建议 ≥ 50 MB）中途点击暂停 → 关闭重启客户端 → 点击继续，正常续传并完成哈希校验发布。
- [ ] **定位本地文件**：已完成的下载任务点击「打开所在文件夹」，正常唤起 `explorer.exe /select,"..."` 并高亮定位到含空格/逗号/中文的文件。
- [ ] **传输中心批量控制**：状态筛选标签、侧栏实时速率胶囊、「全部暂停 / 全部继续 / 重试失败 / 清除已结束记录」全部正常。

## 7. 重装前备份（Windows 专项）

- [ ] 选择本地测试目录（可含空目录、中文/空格路径、深层嵌套）→ 选择云端测试目标目录 → 点击「开始备份」直接边扫描边上传。
- [ ] 验证暂停/继续、失败重试、分页错误明细、抽样/全量哈希校验与清单导出。
- [ ] 验证 Windows 特殊项（长路径 / 保留设备名 / junction 软链接）不会导致崩溃，排除项在报告中如实记录。

## 8. AI 实验室（Beta 测试功能 · 默认关闭）

- [ ] **首次启动默认关闭**：侧边栏**不显示**「对话」入口；设置页「Agent 接入」卡片**隐藏**；无后台命名管道监听。
- [ ] **手动开启 Beta**：进入 **设置 → AI 实验室（Beta 测试功能）** 点击「开启 Beta」→ 侧边栏出现带 `Beta` 标识的「对话」，下方展开「Agent 接入（Beta）」；重启客户端后保持开启。
- [ ] **内置对话（Beta）**：填写 OpenAI 兼容端点 + API Key + 模型名 → 测试连接成功 → 发送只读查询（如“列出根目录”）正常调用工具并返回结果。
- [ ] **Agent 网关（Windows Named Pipe）**：启用 Agent 接入后状态为绿色「运行中」，监听地址显示 `\\.\pipe\...`；执行 `node tools/agent-cli.js status` 可连通并返回状态。
- [ ] **随时关闭**：切换回「关闭」后立即隐藏入口并恢复极简模式；再次开启后已保存配置仍在。

## 9. 卸载清理

- [ ] 通过 Windows「设置 → 应用」执行卸载，安装目录与快捷方式清理干净，无残余后台进程（任务管理器确认无 `QuarkDriveLite.exe` 残留）。
