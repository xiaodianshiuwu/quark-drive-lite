## 0.2.0-rc.1 预发布

PR #1、#2 完成审查后合并到 main。本版支持 Windows x64、Linux x64、macOS Apple Silicon 与 Intel。

- 日常启动取消系统密码/钥匙串要求，登录资料使用 QCK2 / AES-256-GCM 本地随机密钥保存。旧格式可显式迁移并保留备份。备份须同时保留 session.bin 与 session.key；本地密钥不提供系统钥匙串的应用隔离。
- 修复传输完成核对、断点恢复、设置保存一致性、过期 Cookie、运行时 UA、启动导航拦截和便携打包完整性。
- 本机 262 项单测、48 项离线链路、28 项源码冒烟、29 项真实账号 E2E 与 13 项 32 MiB 扩展验收通过；专用测试对象已清理。多 GB 完整回读待后续验收。
- 公开版本已脱敏，旧历史、原始日志、安装标识、官方完整解包及研究附件保留在私有归档；公开完整历史凭据扫描为零候选。

每个压缩包由对应原生 CI 构建和验证，随附 SHA-256 文件。macOS 使用 ad-hoc 签名、未公证，Windows 未做发行者签名；这是预发布版本。

公开范围与脱敏记录：docs/PUBLIC_RELEASE_SECURITY.md。审查与验收边界：docs/REVIEW_2026-10-14.md。
