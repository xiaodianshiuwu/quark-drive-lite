首个公开发布的预发布版本，提供 Windows、Linux 与 macOS 的预构建包。日常启动不再需要输入系统密码或解锁钥匙串。

### 版本主要更新

登录状态改为使用本机随机密钥与 AES-256-GCM 加密保存，Windows、Linux、macOS 一致；同时完成三平台适配，并提供四个平台的预构建包。

### 功能新增

- **免系统密码的登录状态存储**：登录资料使用本机随机密钥加密（密文格式 `QCK2`），日常启动不再触发系统钥匙串或密钥环授权。
- **旧格式显式迁移**：可把早期使用系统加密保存的登录资料转换为新格式，迁移前保留原密文备份。
- **四个平台的预构建包**：Windows x64、Linux x64、macOS Apple Silicon 与 Intel。
- **三平台原生 CI**：Windows、Ubuntu、macOS（Intel 与 Apple Silicon）四个作业分别执行检查、测试、构建与产物冒烟。

### 优化与修复

- **上传结果核对**：传输完成后核对目标文件的可见性与大小，同名等长文件不再被误判为上传成功。
- **下载断点恢复**：续传前校验文件标识、分片大小、总长度与 ETag，任一不匹配即安全重新下载，避免产生损坏文件。
- **设置保存一致性**：设置落盘失败时恢复为已保存的值，界面不再显示未生效的新设置。
- **登录状态判定**：Cookie 已全部过期时不再被判为已登录。
- **请求 UA**：修正固定的 Chromium 版本与运行时不一致的问题。
- **导航拦截**：主窗口的导航与弹窗拦截改为在窗口创建时立即生效。
- **便携包完整性**：Windows 便携版不再二次重写应用归档，避免影响构建校验。

### 下载与安装

| 平台 | 附件 | 系统要求 |
|---|---|---|
| Windows | `quark-drive-lite-0.2.0-rc.1-Windows-x64.zip` | Windows 10 / 11 x64 |
| Linux | `quark-drive-lite-0.2.0-rc.1-Linux-x64.tar.gz` | 主流 x86_64 桌面发行版 |
| macOS（Apple 芯片） | `quark-drive-lite-0.2.0-rc.1-macOS-arm64.zip` | macOS 13 或更高 |
| macOS（Intel 芯片） | `quark-drive-lite-0.2.0-rc.1-macOS-x64.zip` | macOS 13 或更高 |

- **Windows**：解压后双击 `夸克网盘极简版.exe`，免安装。请保持整个文件夹完整。
- **Linux**：`tar -xzf <包名>` 后进入 `linux-unpacked` 目录，运行 `./quark-mini`。
- **macOS**：解压得到 `夸克网盘极简版.app`，首次打开请右键点击图标选择「打开」。

每个附件都附带同名的 `.sha256` 文件，可用于校验下载完整性。完整步骤与校验命令见仓库 [README](https://github.com/xiaodianshiuwu/quark-drive-lite#下载与安装)。

### 注意事项

- **这是预发布版本**，功能与验证范围以仓库 [README 的已知限制章节](https://github.com/xiaodianshiuwu/quark-drive-lite#已知限制)为准。
- **未做发行者签名**：macOS 使用 ad-hoc 签名且未公证，Windows 未做代码签名。首次运行会出现系统安全提示，属于预期行为。
- **登录资料的保护范围**：密钥 `session.key` 与密文 `session.bin` 存放在同一用户目录，能读取该目录的人即可解密，不具备系统钥匙串级别的应用隔离。备份或迁移时必须同时保存这两个文件。
- **传输验证规模**：本版已完成单元测试、集成验证、打包产物冒烟与真实账号端到端验证，传输验证规模为 32 MiB 级别的上传、下载与中断恢复。多 GB 文件的完整回读尚未执行，长时间弱网场景未做专项验证。
- **传输队列不跨重启**：任务列表保存在内存中，关闭应用后需重新选择文件；已下载的临时数据可以续用。
